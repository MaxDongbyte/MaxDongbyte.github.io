免费域名和低价域名注册教程：us.kg | ip-ddns.com

教程：注册免费/低价域名及使用 Cloudflare进行 DNS 管理

本教程将详细介绍如何免费或以极低成本注册域名，并使用 Cloudflare 进行高效管理。我们将涵盖两个主要平台：DigitalPlat FreeDomain 和 ClouDNS，以及它们与 Cloudflare 的结合使用。

1. DigitalPlat FreeDomain (us.kg & dpdns.org)

特点： 提供免费的 dpdns.org 域名，以及低成本的 us.kg 域名（需购买 Key ）。非标准二级域名，限制较多，需要手动提前续期。

1.1 注册账号

  1. 访问网站： 在浏览器中输入 nic.us.kg，它会自动跳转到 dash.domain.digitalplat.org。
  2. 点击注册： 在登录页面下方找到 “Don’t have an account? Sign up“ 并点击。
  3. 填写注册信息：
    • Username (用户名): 填写你想要的用户名。
    • Legal Full Name (全名): 填写你的姓名，姓和名之间至少需要一个空格（例如：lao minggong）。
    • Email (邮箱): 填写你的邮箱地址。
    • Phone (电话): 电话号码格式必须为 +国家区号-XXXXXXXXXX，且包含至少4位数字。可使用虚拟身份生成器生成（例如：+373-067750585）。
    • Full Address (完整地址): 地址必须包含至少20个字符，至少2个逗号，且仅包含英文字符。可使用虚拟身份生成器生成。
    • Password (密码) / Confirm Password (确认密码): 设置你的密码。
    • 人机验证： 勾选 “我不是机器人” 并完成验证。
  4. 点击注册： 填写完毕后，点击 “Register” 按钮。
  5. 邮箱激活： 网站会发送一封激活邮件到你的注册邮箱，点击邮件中的链接进行激活。
  6. 登录： 激活后返回登录页面，输入用户名和密码登录。

1.2 GitHub KYC 验证 (关键步骤)

登录后，DigitalPlat FreeDomain 可能会提示你需要进行 KYC（身份验证）。

  1. 选择验证方式： 在 “US.KG KYC” 页面，选择 “GitHub OAuth”。
  2. 点击授权： 点击 “Sign in with GitHub”。
  3. 登录/注册 GitHub：
    • 如果未登录 GitHub，会跳转到 GitHub 登录页面。
    • 如果没有 GitHub 账号，点击 “New to GitHub? Create an account” 进行注册。
    • GitHub 注册： 填写邮箱、密码、用户名、地区，完成人机验证。GitHub 会发送验证码到你邮箱，输入验证码后完成注册。
    • 登录成功后，GitHub 会提示授权 DigitalPlat FreeDomain 访问你的 GitHub 账号，点击 “Authorize DigitalPlat FreeDomain”。
  4. KYC 验证成功： 授权成功后，页面会提示 “Success! GitHub verification completed! Your account is now KYC verified.”，点击 “Go Back”。

1.3 获取额外域名额度 (可选)

如果你希望注册更多免费域名（例如从 1 个增加到 2 个），可以进行此步骤。

  1. 访问 GitHub 仓库： 在 DigitalPlat FreeDomain 面板的公告板中，找到 “Extra Domain Slot For Those Who Starred Us!” 部分，点击 “Click here to visit our GitHub repo” 跳转到 DigitalPlat 的 GitHub 仓库。
  2. 点亮 “Star”： 在 GitHub 仓库页面的右上角，点击 “Star” 按钮（点亮星星）。
  3. 验证： 返回 DigitalPlat FreeDomain 页面，点击 “Then click here to verify your GitHub account with us”。
  4. 额度增加： 成功后，你的域名额度将从 1 增加到 2。

1.4 注册域名

在 DigitalPlat FreeDomain 面板左侧导航栏点击 “Domain Registration”。

  1. 输入域名： 在 “Domain name” 输入你想要的域名（例如：laominggong）。
  2. 选择后缀：
    • 免费域名 .dpdns.org： 在下拉菜单中选择 .dpdns.org。
    • 低价域名 .us.kg： 在下拉菜单中选择 .us.kg。
  3. 同意条款： 勾选 “I have carefully read and agree to all applicable policies and service terms…”。
  4. 检查可用性： 点击 “Check Availability”。
    • 如果可用，会提示 “Congratulations! This domain name is now available”。
    • 如果已被注册，会提示 “Sorry, this domain name is already registered.”，需要更换域名或后缀。
  5. 配置 Nameserver (重要！)
    • 在 “Domain Checkout” 页面，你需要填入 Nameserver。
    • 我们强烈推荐使用 Cloudflare 的免费 DNS 管理服务。
    • 在 Cloudflare 注册并获取 Nameserver 地址： （详见下方 2. Cloudflare 部分）
    • 将 Cloudflare 提供的两个 Nameserver 地址分别填入 “Name Server 1” 和 “Name Server 2” 字段。
    • 注意： us.kg 后缀的域名在注册时，还需要填写你在 1.2 步骤中购买的 KYC Key。
  6. 点击注册： 点击 “Register!” 按钮。
  7. 注册成功： 页面会提示 “Registration Successful”。

1.5 域名续期 (DigitalPlat 特有)

  • dpdns.org 和 us.kg 域名： 这些域名都是永久免费的，但需要你手动续期。
  • 续期规则： 当域名距离过期不到 180 天时，你需要在 DigitalPlat FreeDomain 的域名管理页面点击 “Renew” 按钮进行手动续期。提前点击是无效的。

2. Cloudflare (全球领先的 DNS 管理服务)

特点： 可用于管理任何顶级域名和部分二级域名的 DNS 解析，提供免费 CDN 加速、SSL 证书和安全防护，设置简单稳定。

2.1 注册账号

  1. 访问网站： cloudflare.com
  2. 点击注册： 点击右上角的 “Sign Up” 按钮。
  3. 填写注册信息： 输入邮箱和密码，完成人机验证。
  4. 邮箱激活： Cloudflare 会发送激活邮件，点击链接激活账号。
  5. 登录： 激活后登录 Cloudflare 面板。

2.2 添加域名并配置 DNS

  1. 添加站点： 在 Cloudflare 面板，点击 “Add a site” (添加站点)。
  2. 输入域名： 输入你刚在 DigitalPlat 或其他平台注册的域名（例如：laominggong.dpdns.org 或 laominggong.us.kg 或 minggong.ip-ddns.com）。
  3. 选择计划： 选择 “Free” 计划，点击 “Continue”。
  4. 扫描 DNS 记录： Cloudflare 会自动扫描你域名当前的 DNS 记录。
    • 注意： 如果是从 ClouDNS 导入域名，它会自动导入 ClouDNS 的默认记录，这些记录通常不需要，建议全部删除。
  5. 提供 Nameserver： Cloudflare 会提供两个 Nameserver 地址（例如 fred.ns.cloudflare.com 和 magali.ns.cloudflare.com）。
    • 重要！ 将这两个地址复制下来。
    • 回到你注册域名的平台（DigitalPlat FreeDomain 或 ClouDNS），将域名的 Nameserver 设置更新为 Cloudflare 提供的这两个地址。
  6. 完成设置： 回到 Cloudflare 页面，点击 “Done, check nameservers” (完成，检查名称服务器)。
  7. 等待验证： Cloudflare 需要几分钟到几小时来验证 Nameserver 更新。验证成功后，你的域名状态会显示为 “Active” (活动)。

2.3 添加解析记录

在 Cloudflare 面板左侧导航栏点击 “DNS”。

  1. 删除旧记录 (如果存在)： 如果你的域名是从其他平台转移过来，并且 Cloudflare 自动导入了一些不需要的记录，建议全部删除。
    • 勾选记录旁边的复选框，然后在底部的 “Copy” 下拉菜单中选择 “Delete”，点击 “Execute”。
  2. 添加 A 记录 (指向服务器 IP)：
    • 点击 “Add record” (添加记录)。
    • Type (类型): 选择 “A”。
    • Name (名称):
      • 填写 @ (代表主域名，例如 你的域名.com)。
      • 或填写 www (代表 www.你的域名.com)。
      • 或其他子域名（例如 blog 代表 blog.你的域名.com）。
    • IPv4 address (IPv4 地址): 填写你的服务器 IP 地址。
    • Proxy status (代理状态): 建议保持 “Proxied” (代理) 开启，以获得 Cloudflare 的 CDN 加速和安全防护。
    • TTL (生存时间): 保持 “Auto” (自动)。
    • 点击 “Save” (保存)。
  3. 添加 CNAME 记录 (指向另一个域名)： 如果你需要将子域名指向另一个域名（例如将 www.你的域名.com 指向 你的域名.com）。
    • 点击 “Add record”。
    • Type (类型): 选择 “CNAME”。
    • Name (名称): 填写你想要指向的子域名（例如：www）。
    • Target (目标): 填写目标域名（例如：你的域名.com）。
    • Proxy status (代理状态): 建议保持 “Proxied” 开启。
    • 点击 “Save”。

3. ClouDNS (ip-ddns.com) 的特殊情况

特点： 提供免费的 ip-ddns.com 域名。使用简便，但免费域名类型非标准，且需要双向解析（在 ClouDNS 和 Cloudflare 都配置），对新手不友好。

  • 双向解析： ClouDNS 的免费域名，如果你选择使用 Cloudflare 进行 DNS 管理，那么你需要进行双向解析：
    1. 在 ClouDNS 中设置 Nameserver 指向 Cloudflare： 这是将 DNS 解析权委托给 Cloudflare 的第一步。
    2. 在 Cloudflare 中添加 A 记录或 CNAME 记录指向你的服务器： 这是实际的解析步骤。
    3. 在 ClouDNS 中也要保留或添加解析记录： 这是 ClouDNS 免费域名的特殊要求，即使解析权给了 Cloudflare，ClouDNS 端也需要有相应的记录才能正常工作。
      • 注意： 在 ClouDNS 免费域名中，默认的 A 记录和 CNAME 记录通常是存在的。如果你删除了它们，可能需要手动添加回来，并且它们的目标需要指向你的服务器 IP 或 CNAME。
