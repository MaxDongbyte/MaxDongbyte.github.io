Gemini in Chrome & Copilot in Edge AI工具栏开启及PuTTY登录工具使用介绍

一、在Google Chrome浏览器中启用Gemini按钮

要在 Chrome 浏览器中使用内置的 Gemini in Chrome（开发代号为 glic） 功能，需要完成两部分设置：前置环境准备与高级参数配置。由于该功能目前处于分阶段推送中，且仅对部分地区开放，可能需要手动修改配置文件来强制开启。

第一步：前置准备

  • 1.升级 Chrome：将浏览器升级至最新版本（访问 chrome://settings/help 自动检查更新）。
  • 2.区域与网络：网络 IP 切换至美国地区。以美区 Google 账号登录。
  • 3.系统语言：尽量将 Chrome 的界面语言设置为英语（美国）/ English (US)。在 chrome://settings/languages 中进行设置。 将语言移到顶部，勾选 “以此语言显示 Chrome 界面内容”

第二步：启用功能与权限设置

  • 1.强制开启实验室底层开关（Flags 实验功能）如果在常规设置里找不到 Gemini，需要先在开发者实验选项中将其强制激活：
    • 在浏览器地址栏输入 chrome://flags/#glic 回车。
    • 页面会自动高亮标出与 Glic（Gemini 桌面版代号）相关的实验项。将 Glic、Glic actor 和 Glic side panel 等相关选项右侧的下拉菜单由 Default 改为 Enabled（启用）。Glic side panel 选项如果没有就略过。
  • 2.点击页面弹出的 Relaunch（重新启动）以应用更改

第三步：开启高级配置

由于当前此功能未向所有地区默认开放，需要通过修改浏览器的配置文件来解锁资格：

  • 1.完全关闭 Chrome：确保没有任何 Chrome 进程在后台运行（在任务管理器中确认）。

  • 2.找到配置文件：根据操作系统，找到Chrome的配置文件，最好先备份一份：

    • 文件所在路径：C:\Users\用户名\AppData\Local\Google\Chrome\User Data 将”用户名”替换为你的windows的登录名称即可
    • Windows系统：%LOCALAPPDATA%\Google\Chrome\User Data\Local State
    • macOS系统：~/Library/Application Support/Google/Chrome/Local State

  • 3.修改文件内容：用记事本或任何纯文本编辑器打开Local State，搜索并修改以下五个字段：

    • "is_glic_eligible": true
    • "variations_country": "us"
    • "variations_permanent_consistency_country": "us"
    • "variations_safe_seed_permanent_consistency_country":"us"
    • "variations_safe_seed_session_consistency_country":"us"

  • 4.保存文件并重新启动 Chrome。

  • 5.浏览器重启后，在工具栏（右上角）会出现 Gemini 图标。

二、Edge浏览器中Copilot按钮开启步骤

  • 1.使用美区的梯子
    1. 进入电脑系统设置 -> 时间和语言 -> 将国家改为美国
    1. 语言和区域 中 windows显示语言 改为 英文
    1. 升级 Edge：将浏览器升级至最新版本（访问 edge://settings/help 自动检查更新）。
    1. Edge的地址栏里输入：edge://flags/#edge-copilot
    • 将Edge Copilot Mode 设置为 Enable
    • 将Copilot App Configuration 设置为 Enable
    1. Edge的地址栏里输入：edge://settings/languages
    • 如果没有 English (United States) 选项就点击添加 然后将其移到顶端，选择 “以这种语言显示 Microsoft Edge”
    1. 浏览器重启后，在工具栏（右上角）会出现 Copilot 图标。
