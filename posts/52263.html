1. 背景与原理

自建 VPS（Virtual Private Server）是目前最稳定、最灵活的网络流量分流方式之一。相比购买成品机场，自建 VPS 的优势在于：

  • 稳定性更高：节点独享，不与他人共享带宽。
  • 隐私性更强：流量不经过第三方服务商。
  • 可控性更强：可自由选择国家、地区、带宽、协议。
  • 成本更低：长期使用比机场便宜得多。

原理非常简单：

  1. 在云服务商购买或申请 VPS（服务器）。
  2. 在 VPS 上安装代理协议（如 Xray、Sing-box、Hysteria，一般通过安装3x-ui面板等来实现）。
  3. 将 VPS 的 IP + 端口生成节点链接。
  4. 在客户端导入节点即可使用。

2. 适用场景

以下用户最适合自建 VPS：

✔ 需要稳定网络流量分流

机场经常抽风，自建 VPS 稳定性更高。

✔ 需要海外身份体系

如 Google、OpenAI、Claude、海外银行、海外 App。

✔ 需要跨境工作

自建 VPS 可选择目标国家的 IP，适配各种服务。

✔ 需要高隐私、高安全

流量不经过第三方，更适合敏感业务。

✔ 想降低长期成本

机场长期订阅费用高，自建 VPS 更划算。

3. 风险与限制

❗ 1. 自建 VPS 需要一定技术基础

需要会使用 SSH、命令行、配置文件。

❗ 2. 免费 VPS 有严格限制

如 Google Cloud、AWS 免费额度有限，随着各家政策的变动可能随时失效。

❗ 3. 部分地区的 VPS 不适合网络流量分流

如韩国、日本部分机房可能会主动封锁代理协议。

❗ 4. 自建节点可能被滥用

如果配置不当，可能被扫描、攻击或盗用流量。

❗ 5. 云服务商可能封禁账号

尤其是免费 VPS（像Oracle等），风控较严格。

❗ 6. 并非所有人都适合自建

如果你不想维护服务器，机场更适合你。

5. 常见错误与解决方案

❌ 1. VPS 无法连接

原因： 防火墙未开放端口
解决： 在云服务商后台开放 80/443/任意端口

❌ 2. 节点无法使用

原因： 配置文件错误，服务器或客户端的时间同步问题等
解决： 检查 UUID、端口、路径是否一致

❌ 3. Google Cloud / AWS 免费额度失效

原因： 超出使用量
解决： 先查看账单与用量明细，停止产生额外费用的资源，再根据云厂商规则调整实例或套餐。不要通过反复删除、重建实例规避免费额度限制。

❌ 4. IP 被封

原因： 使用敏感协议或被攻击
解决： 更换 IP 或更换机房

❌ 5. SSH 无法登录

原因： 密钥错误或端口被封
解决： 重置密钥或使用控制台登录

6. 真实使用体验

✔ 免费 VPS 不稳定，但适合学习

Google Cloud、AWS 免费额度适合新手练手，AWS长期来看不太稳定，随时可能会被封号。

✔ RackNerd 是性价比最高的收费 VPS

便宜、稳定、适合长期自建节点。

✔ Vultr 适合需要相对高质量 IP 的用户，但价格较Racknerd高

IP 干净，适合注册海外服务。

✔ 自建节点比机场稳定太多

尤其是长期使用，延迟更低、速度更快。

✔ 维护成本不高

只要配置一次，后续几乎不用管。

7. 总结与建议

✔ 新手建议从免费 VPS 入门

如 Google Cloud、AWS。

✔ 长期使用建议购买 RackNerd 或 Vultr 或者搬瓦工

稳定、便宜、适合网络流量分流。

✔ 自建节点更适合追求稳定与隐私的用户

机场适合不想折腾的人。

✔ 自建 VPS 是最值得投入的技术之一

长期成本低、稳定性高、隐私性强。

8. KVM 类 VPS 与共享核心容器类 VPS的区别（重要背景知识）

8.1 什么是 KVM 类 VPS？

KVM 是真正的硬件虚拟化技术，每个 VPS 都拥有：

  • 独立内核
  • 独立内存空间
  • 完整系统环境

⭐ KVM 的优势

  • 隔离性强
  • 稳定性高
  • 支持所有代理协议（Xray、Hysteria、Sing-box）
  • 可安装 BBR、TFO 等优化
  • 适合长期自建节点

8.2 什么是容器类 VPS（OpenVZ / LXC）？

容器 VPS 共享宿主机内核，通过隔离层提供环境。

⭐ 容器 VPS 的优势

  • 价格便宜
  • 资源利用率高

⭐ 容器 VPS 的限制

  • 无法更换内核
  • 无法运行 Hysteria、TUIC 等协议
  • 隔离性弱
  • 容易出现 CPU 被抢占、网络抖动

8.3 核心区别对比

项目 KVM VPS 容器 VPS
虚拟化类型 完整硬件虚拟化 容器隔离
内核 独立 共享
稳定性 高 中等偏低
隔离性 强 弱
支持协议 全部支持 部分受限
是否适合自建节点 ✔ 强烈推荐 ❌ 特写脚本可用

8.4 为什么通常优先考虑 KVM？

  • 稳定性更高
  • 协议兼容性更好
  • 隐私隔离更强
  • 性能更稳定

结论：需要独立内核、完整权限或特定网络功能时优先考虑 KVM；普通网站和轻量服务也可以使用配置合适的容器 VPS。不要运行来源不明的一键脚本。

8.5 如何判断 VPS 类型？

运行：

  • 返回标准 Linux 内核 → KVM

  • 返回宿主机统一内核 → 容器 VPS

8.6 哪些服务商提供 KVM？

  • RackNerd
  • Vultr
  • 搬瓦工
  • Google Cloud
  • AWS
